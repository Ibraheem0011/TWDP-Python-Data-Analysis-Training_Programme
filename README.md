# TWDP-Python-Data-Analysis-Training_Programme
TWDP | Hands-on Python for data analysis: practical scripts and notebooks from the training programme, covering data handling, statistics, and visualization.

## Overview

This repository contains the code, notebooks, and exercises from the [TWDP] Python Data Analysis Training Programme, held [August-October,2026] [online and in person].

## What was covered

- Data handling with pandas and NumPy
- Data cleaning and preprocessing
- Descriptive statistics and hypothesis testing
- Data visualization with Matplotlib and Seaborn

## Repository structure

```

├── week8_pandas/
├── week9_visualization/
├── data/              # sample datasets only
├── requirements.txt
└── README.md
```

## Data

Datasets in the `data/`folder are from the instructor and dummy data used for practice.[Kaggle]

Python 3.x, pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook
